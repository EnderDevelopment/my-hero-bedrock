# أبطال UA Minecraft Bedrock Add-on

أبطال UA is a Minecraft Bedrock add-on and superhero academy mod that adds four command-activated powers using vanilla effects, movement, particles, sounds, and combat abilities.

## Install

1. Make sure Minecraft Bedrock Edition 1.21.50 or newer is installed.
2. From the project root, run:
   ```sh
   python3 package_mcaddon.py
   ```
3. Open the generated `HeroAcademy.mcaddon` file to import the add-on into Minecraft.
4. Edit or create a world.
5. Enable both the Hero Academy Behavior Pack and Hero Academy Resource Pack.
6. Enable cheats in the world.

## Use

Run one of these commands in the chat to activate a power for yourself:

```text
/function hero/one_for_all
/function hero/explosion
/function hero/zero_gravity
/function hero/engine
```

Available powers:

- One For All: Grants strength, speed, and a short regeneration boost.
- Explosion: Grants strength and fire resistance, creates an explosion particle and sound, then moves the player forward.
- Zero Gravity: Grants slow falling, jump boost, and short levitation.
- Engine: Grants speed, haste, and jump boost for faster movement and mining.
